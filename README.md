# Diagram Image Enhancer

Open the tool: **https://rakshita-singh-13.github.io/diagram-enhancer/**

A browser tool for exam diagrams and symbol figures (biology, chemistry structures, physics, mental ability, symbol series).

- **Vector smooth** – traces black line diagrams into perfectly smooth curves (PNG or SVG).
- **Crisp** – sharpens while keeping grey shading, coloured boxes and coloured lines.
- **Enhance** – upscale, sharpen, clean background.
- **Retype symbols** – reads symbol-series rows (built-in offline reader trained on the book's own symbols) and redraws them with clean font symbols; click any symbol to fix it, and the reader learns.

Everything runs inside the viewer's browser: images are never uploaded anywhere.
Updating `index.html` in this repository updates the live tool for everyone.
